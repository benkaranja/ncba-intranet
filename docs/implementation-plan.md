## 4. Locked image slots

Three slots (the `sidebar-tile` slot was retired in D-042). Every instance of a slot uses exactly one dimension. Full detail in `docs/component-specs.md`.

| Slot | Locked size | Ratio | Used by |
|---|---|---|---|
| `hero-banner` | **1920 × 310** | 6.19:1 | Page header banner, all 7 pages, full-bleed |
| `media-16x9` | **940 × 529** | 16:9 | Carousel slides, video thumbnails, full-width feature images, article hero |
| `loop-thumb` | **320 × 180** | 16:9 | Blog-post loop side image (news + video variants) |

**Crop rules (verified visually before locking):**
- 16:9-native sources (1920×1080) → **no crop** at `media-16x9`. Chosen specifically so KV headline text and the "Go for it" badge are never clipped.
- 1:1 sources (1080×1080 ESHOT/POST) → **top-anchored** crop. Centre-cropping decapitates the headlines; top-anchoring keeps headline + face and drops only the lower CTA line.
- Photographs → centre crop, anchored 0.18 from top at `hero-banner` so the subject's face lands in the band.

**Secondary nav** (white strip under the magenta header, on L2/L3 pages): the four full country names, **each carrying a dropdown** of `MCC` · `Strategy` · `Human Resources` (decision D-038). Active country is bolded with a magenta underline; the active department is highlighted inside its dropdown.

**Link policy — zero dead links:** every `href` resolves to one of the 7 files or to a real in-page anchor (`#main`, `#news`, `#events`, `#help`). Nav items without a built page point at the current page's `#main`. Contact emails in "We're Here to Help" render as plain text, not `mailto:` links, so the link checker stays meaningful.

## 9. Risks and mitigations

| Risk | Mitigation |
|---|---|
| Banned string leaks in via copied markup | Nothing is copied from the reference screenshot; all copy is newly written; Phase 4 grep gates delivery |
| Image slot drift | All images written by one script at four fixed sizes; Phase 4 asserts dimensions on disk |
| Dead links from placeholder `href="#"` | Every placeholder points at a real anchor id that exists in the page; checker validates anchor targets too |
| Brand guide drifting from CSS | Guide is written first as the spec, then reconciled against `ncba.css` in Phase 4 before sign-off |
| Nav overflow at 10 items | 14px/600 at 1300px canvas fits; below 1024px the nav scrolls horizontally rather than wrapping |
